# StayFinder

This repository contains the StayFinder backend and a folder for the future frontend.

```text
stayfinder-stays/
├── backend/    # Hono API, TypeScript source, tests, and npm configuration
└── frontend/   # Reserved for the frontend application
```

## Run the backend

Requires Node.js 20 or newer and npm. From the repository root:

```bash
cd backend
npm install
npm run dev
```

See [the backend README](backend/README.md) for environment setup, API routes,
and available commands. Run all backend npm commands from `backend/`.
